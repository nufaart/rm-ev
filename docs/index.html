CYBER EV ENGINE
v—

HUD Kecepatan & Suara Engine

Aplikasi Android untuk motor EV Anda: kecepatan dari GPS, suara cruising yang stabil per rentang kecepatan, suara akselerasi di atas 40 km/jam, dan engine brake saat turun kecepatan besar. Bisa tetap berjalan di latar belakang.

Unduh APK
Versi: — Ukuran: — Rilis: — Android 7.0+

Cara memasang

  1. Tekan Unduh APK di atas, lalu tunggu unduhan selesai.
  2. Buka file rm-ev.apk dari notifikasi unduhan atau folder Download.
  3. Jika diminta, izinkan Pasang aplikasi dari sumber ini untuk browser Anda.
  4. Buka CYBER EV ENGINE, izinkan akses lokasi dan notifikasi.
  5. Tekan START ENGINE. Notifikasi "Engine aktif" akan muncul saat app berjalan di latar belakang.

APK ini dibagikan langsung, bukan dari Play Store, jadi Android akan menampilkan peringatan saat pemasangan. Unduh hanya dari halaman ini.

Fitur

Suara 3 modeIDLE saat diam, CRUISING stabil per rentang kecepatan, dan ENGINE BRAKE saat turun kecepatan besar.
Akselerasi di atas 40 km/jamSuara otomatis berubah ke akselerasi saat melewati 40 km/jam.
Cruising atau AkselerasiPilih karakter suara cruising untuk kecepatan di bawah 40 km/jam.
Jenis motorPilih karakter knalpot: Inline-4, R1 Crossplane, 2-Tak, Matic, Single, atau Harley V-Twin.
Cek updateTombol CEK UPDATE di aplikasi memeriksa versi terbaru.
